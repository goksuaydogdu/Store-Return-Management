# Store Return Management System

A C# Windows Forms application for managing store returns, customers, return items, user sessions, and reports.

## Tech Stack
- C#
- .NET 10 (Windows Forms)
- SQL Server
- Microsoft.Data.SqlClient

## Main Components
- Login and session handling
- Customer and return management
- Return-item repositories
- Reporting screens
- Data-access layer

## Run Locally
1. Open `MagazaIadeOtomasyonu.sln` in Visual Studio on Windows.
2. Make sure the .NET 10 SDK and Windows Desktop workload are installed.
3. Configure the SQL Server connection string in `Data/DbHelper.cs`.
4. Create the `MagazaIadeDb` database and required tables.
5. Build and run the solution.

> This is an academic portfolio project. The database schema is not included. A demonstration account exists in the source; do not reuse sample credentials in a real system.
